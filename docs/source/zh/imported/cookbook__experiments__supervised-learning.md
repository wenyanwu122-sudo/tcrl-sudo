# SFT 对比实验

本章节用于记录基于 tcrl_infra 的 SFT 对比实验结果。实验 1-2 验证 TCRL 与 Tinker 的训练等价性；实验 3-4 通过与多个 Proxy Model（小模型）和 Oracle Model（大模型）的结果对比，展示从小模型到大模型再到 TCRL SFT 后模型的性能提升路径，验证 TCRL（chat_sl）在文本分类任务上的有效性。

## 实验 1：no_robots 数据集[​](\#实验-1no_robots-数据集)

### 实验配置[​](\#实验配置)

- **模型**
  
  : Qwen/Qwen3-8B-Base
- **任务**
  
  : no_robots 数据集上的 SFT 训练
- **LoRA 配置**
  
  : 64 rank, 5e-4 learning rate
- **训练配置**
  
  : 64 batch size, 1 epoch, Cosine Decay
- **训练步数**
  
  : 148 steps
- **Eval 间隔**
  
  : 每 20 steps

### 核心发现[​](\#核心发现)

TCRL 和 Tinker 在 no_robots 任务上取得了几乎一致的最终性能：

1. **最终性能相当**
  
  : 测试集 NLL 仅相差 0.0025，几乎可以忽略不计。
2. **训练动态相似**
  
  : 两者的 Train NLL 下降曲线呈现出高度一致的趋势。
3. **初始状态一致**
  
  : 初始 test/nll 差异仅 0.0001，证明模型初始化和数据加载完全一致。

- **训练配置**

- **分析步数**
  
  : 212 steps (Step 0-211)
- **数据规模**
  
  : ~7330 steps/epoch

### 核心发现[​](\#核心发现-1)

TCRL 和 Tinker 在 tulu3 大规模数据集上取得了高度一致的训练表现：

1. **初始状态完全一致**
  
  : test/nll 差异仅 0.0004，证明模型初始化和数据加载一致。
2. **训练动态相似**
  
  : 各阶段 train_mean_nll 均值差异均在 0.002-0.007 范围内。
3. **Loss 计算方式一致**
  
  : 两者
  
  `num_loss_tokens`
  
  均为 ~128（per-sequence 归一化），NLL 可直接对比。

## 实验 3：SST-5 情感分类[​](\#实验-3sst-5-情感分类)

**目标：** 验证 TCRL（chat_sl）在小规模数据集上的 SFT 效果，展示从小模型到大模型再到 TCRL SFT 后模型的性能提升路径。

**模型：** Qwen/Qwen3-8B-Base, Qwen/Qwen3-8B

**数据集：** SST-5 五分类情感分析（训练集 8,544 条，测试集 2,210 条）

### 实验配置[​](\#实验配置-2)

| 配置项 | TCRL (Qwen3-8B-Base) | TCRL (Qwen3-8B) |
| --- | --- | --- |
| LoRA rank | 64 | 64 |
| Learning rate | 5e-4 | 5e-4 |
| Batch size | 64 | 64 |
| Eval every | 20 steps | 20 steps |
| 总训练步数 | 133 | 133 |

### 训练效率[​](\#训练效率)

| 指标 | TCRL (Qwen3-8B-Base) | TCRL (Qwen3-8B) |
| --- | --- | --- |
| 总训练时间 | 19.0 min | 10.3 min |
| 平均步耗时 | 8.58s | 4.64s |
| 纯训练平均步耗时 | 7.87s | 3.87s |
| 初始 Test NLL | 1.3670 | 23.4568 |
| 最终 Test NLL | 0.2063 | 0.4000 |
| NLL 下降幅度 | -1.1607 | -23.0568 |

:::info 训练效率说明
Qwen3-8B 的平均步耗时（3.87s）显著低于 Qwen3-8B-Base（7.87s），这是因为 Instruct 模型已具备指令跟随能力，训练收敛更快，而 Base 模型需要更多的梯度更新来学习输出格式。
:::

### 实验结果[​](\#实验结果)

| 方法 | 模型 | Accuracy |
| --- | --- | --- |
| Proxy Model | Qwen2.5-1.5B-Instruct | 27.15% |
| Proxy Model | Qwen2.5-3B-Instruct | 46.61% |
| Proxy Model | Qwen3-8B-Base | 10.45% |
| Proxy Model | Qwen3-8B | 43.26% |
| Oracle Model | Qwen3-30B-A3B-Instruct | 56.74% |
| Oracle Model | DeepSeek-V3.2 | 50.59% |
| TCRL (chat_sl) | Qwen3-8B-Base | 43.76% |
| TCRL (chat_sl) | Qwen3-8B | 58.91% |

### 结论[​](\#结论-2)

1. **TCRL SFT 有效提升模型表现**: Qwen3-8B 经过 TCRL SFT 后达到 58.91%，超越了 Oracle 模型 Qwen3-30B-A3B-Instruct（56.74%）和 DeepSeek-V3.2（50.59%），证明了 SFT 的有效性。
2. **基座模型选择的重要性**: Qwen3-8B 经过 SFT 后（58.91%）显著优于 Qwen3-8B-Base 经过相同 SFT 后的结果（43.76%），说明在 Instruct 模型基础上进行 SFT 效果更好。
3. **从小模型到大模型的提升路径清晰**: 1.5B（27.15%）→ 3B（46.61%）→ 8B SFT（58.91%），模型能力随规模和训练逐步提升。

2. **大规模数据集上基座模型差距缩小**: 在 AGNews 大规模数据集上，Qwen3-8B-Base（95.50%）与 Qwen3-8B（96.05%）经过 SFT 后的差距仅 0.55%，远小于 SST-5 上的 15.15% 差距，说明充足的训练数据可以弥补 Base 模型与 Instruct 模型之间的能力差距。
3. **从小模型到大模型的提升路径清晰**: 1.5B（51.40%）→ 3B（69.90%）→ 8B SFT（96.05%），在大规模数据集上 SFT 的效果尤为显著。

### 核心结论[​](\#核心结论)

1. **SFT 有效超越大模型**: 使用 Qwen3-8B 模型进行 TCRL SFT 后，在全部七个数据集上均大幅超越 30B 级别大模型。DBPedia 达到 99.50%（+2.80%）；THUCNews 达到 98.80%（+8.80%）；AGNews 达到 96.05%（+9.55%）；SST-2 达到 96.79%（+2.64%）；IMDb 达到 95.75%（+2.15%）；TNews 达到 69.19%（+12.65%）；SST-5 达到 58.91%，超越所有 Oracle 模型。
2. **Instruct 模型 SFT 效果因任务而异**: 在英文短文本任务（SST-5、AGNews、SST-2）上 Qwen3-8B 优于 Qwen3-8B-Base；在长文本二分类任务（IMDb）和中文短文本任务（TNews）上 Qwen3-8B-Base 略优；在超大规模数据集（DBPedia）和中文长文本任务（THUCNews）上两者表现一致。不同任务的最优基座模型选择需要实验验证。
3. **数据规模影响基座模型差距**: 在超大数据集 DBPedia（560K）上差距仅 0.10%；THUCNews（46K）上差距 0.00%；AGNews（120K）上差距 0.55%；SST-2（67K）上差距 0.46%；IMDb（25K）上差距 0.75%；TNews（53K）上差距 1.20%；小数据集 SST-5（8.5K）上差距达到 15.15%。充足的训练数据是 SFT 成功的关键因素。
4. **训练效率合理**: SST-5 任务约 10 分钟，IMDb 任务约 1.6 小时，TNews 任务约 1.6 小时，SST-2 任务约 2.0 小时，AGNews 任务约 2.2 小时，THUCNews 任务约 3.1 小时，DBPedia 任务约 4.2 小时，平均步耗时 8~31s，训练效率满足实际使用需求。
