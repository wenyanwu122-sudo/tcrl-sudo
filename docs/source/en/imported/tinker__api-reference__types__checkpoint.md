# tinker.types.Checkpoint

## *class* [**tinker.types.Checkpoint**](https://github.com/thinking-machines-lab/tinker/blob/main/src/tinker/types/checkpoint.py\#L11)(*BaseModel*)[​](\#class-tinkertypescheckpointbasemodel)

**Fields:**

- **checkpoint_id**
  
  – The checkpoint ID
- **checkpoint_type**
  
  – The type of checkpoint (training or sampler)
- **time**
  
  – The time when the checkpoint was created
- **tinker_path**
  
  – The tinker path to the checkpoint
- **size_bytes**
  
  – The size of the checkpoint in bytes
- **public**
  
  – Whether the checkpoint is publicly accessible
- **expires_at**
  
  – When this checkpoint expires (None = never expires)
